# BFSI Compliance RAG — Air-Gapped Regulatory Research Assistant

A fully offline, air-gapped Retrieval-Augmented Generation (RAG) pipeline for querying EU financial regulations. Runs on a 4GB USB drive with zero cloud dependencies, zero marginal cost per query, and full audit-trail traceability.

## 🎯 What This Does

Ask a plain-English question about EU financial regulation, get a grounded, cited answer generated by a local LLM that runs entirely on your machine. If the answer isn't in the corpus, the system refuses to guess.

**Example:**
> **Query:** "What are the customer due diligence requirements?"
> **Answer:** "Under Regulation (EU) 2024/1624, Article 19, obliged entities must apply customer due diligence measures including..."
> **Source:** CELEX 32024R1624, Article 19

---

## ✨ Key Features

- **100% offline** — no API calls, no data leaves the machine
- **6 EU regulations ingested** — GDPR, AI Act, AML Regulation, AML Directive, AMLA Regulation, CRR3
- **5,500+ legal chunks** with article-level metadata
- **Fail-closed architecture** — refuses out-of-scope queries (verified 0% false positive rate)
- **Audit trail** — every answer tied to a source URL and SHA-256 hash
- **CPU-only** — no GPU required; runs on standard hardware
- **~11ms retrieval latency**, ~12s end-to-end LLM generation

## 🚀 Quick Start

### Prerequisites
- Python 3.11+
- [Ollama](https://ollama.com/) installed and running
- ~4 GB free disk space

### Installation

```bash
# 1. Clone and enter the project
git clone https://github.com/yourusername/bfsi-compliance-rag.git
cd bfsi-compliance-rag

# 2. Create virtual environment
python -m venv .venv
source .venv/bin/activate  # Windows: .venv\Scriptsctivate

# 3. Install dependencies
pip install -r requirements.txt

# 4. Pull the local model
ollama pull llama3.2:3b
ollama pull nomic-embed-text

# 5. Ingest the regulatory corpus
python build_dataset.py

# 6. Start the web interface
python app.py
```

Open `http://127.0.0.1:8001` in your browser.

## 🛡️ Design Principles

- **Fail closed, not open.** Out-of-domain queries must refuse, not guess.
- **Evidence over eloquence.** Every answer links to a source URL and hash.
- **Air-gapped by default.** No network calls in the runtime path.
- **Honest metrics.** Report confidence intervals; flag small sample sizes.
- **Isolate noisy data.** Sanctions lists (`ofsi_sanctions.jsonl`) are kept separate from the legal corpus.
